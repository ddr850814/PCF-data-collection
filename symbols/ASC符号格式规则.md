# Isogen Symbol Editor .ASC 符号文件格式规则

> 来源：由 `1.asc`（Symbol Editor 导出）逆向解码，经 01HG/ANCH/HANG/SPRG/SKID 等符号几何逐笔验证。
> 解析器实现：`pcf/asc_symbols.py`；渲染接入：`pcf/render.py` 的 `_draw_support_symbol`。
> Smart Isogen 的 SKEY 语义与方向模式参考：`x64\Smart Isogen\Data\SystemMaterialData.xml`。

## 一、文件结构

文件由三种记录组成，按行排列：

```
501 <SKEY...> <数字参数...>     符号开始（可省略 999 直接连下一个 501）
502 <el#> <x> <y> <pen> ...     几何记录（一个符号可有多条）
999                             符号结束（整个文件可只在末尾出现一次）
```

### 501 记录（符号头）

```
501  01HG  100  0  0  0  0  0  0  0  0  0
     └┬┘   └┬┘ └──────────┬─────────┘ └┬┘
    SKEY   尺寸   原点等参数(8个)      方向模式
```

- **SKEY**：可挂多个（如 `501 SLVE 01HG ...` 表示两个 SKEY 共用同一几何）
- **方向模式**（最后一个数字）：
  | 值 | 含义 | 例 |
  |---|---|---|
  | 0 | 顺管道方向：符号 X 轴对齐管道轴向，跨管偏移沿垂直世界轴的 30° 投影 | 01HG、SLVE |
  | 2 | 固定方向：配合 PCF 的 `SUPPORT-DIRECTION`（UP/DOWN）上下翻转 | GUID、HANG、SKID、SPRG、DUCK |
  | 3 | 三轴同画：X/Y/Z 三个世界轴向各画一次符号几何 | ANCH |

### 502 记录（几何）

```
502  1  170 200 1  0 400 2  350 400 1  350 0 0
     └┬┘ └────────┬────────┘
   元素号   (x, y, pen) 三元组序列
```

- 第二个字段（元素号）对本解码规则无影响
- 每个三元组 `(x, y, pen)` 描述画笔经过的一个点及动作

## 二、画笔语义（核心规则）

```
1. 记录之间笔位连续传递（上一条 502 停在哪，下一条从哪开始）
2. 第一条 502 记录冷启动于其首点 —— 该点即符号连接点（管道挂点），
   没有到达段
3. 到达段（后续记录的首点）：
     pen 1 / 2 / 6  →  从上一记录末点画线到本点
4. 离开段（本点 → 下一点）：
     pen 2  →  画线
     pen 1  →  空移（不画线）
     pen 6  →  不画（pen 6 只画到达段，不画离开段）
     pen 0  →  停止（本点为终点）
```

记忆口诀：**"到达 1/2/6 都画，离开只有 2 画"**。

## 三、坐标系与放置

- 坐标为符号局部空间，单位任意；渲染时按包围盒归一化到约 4.5mm
- **连接点 = 第一条 502 记录的首点**（不是 501 头部的 origin 参数！），
  所有几何平移到连接点为原点
- 验证例：01HG 首点 (170,200) ≈ 包围盒中心 (175,200)；ANCH 首点 (2000,250) = 中心分毫不差
- 渲染朝向：
  - 模式 0：X 轴 → 最近管段方向；Y 轴 → 垂直于管轴的世界水平轴投影（30° 斜向）
  - 模式 2：固定；SUPPORT-DIRECTION=UP 时 Y 翻转
  - 模式 3：X 轴分别取世界 X/Y/Z 轴投影，画三次

## 四、已验证符号（1.asc）

| SKEY | 段数 | 形状 | 方向模式 |
|---|---|---|---|
| 01HG | 2 | 两条平行线跨在管道两侧 | 0 顺管道 |
| ANCH | 5 | 连续轴线穿过定位点 + 四翼组成两个收敛箭头（▷◁） | 3 三轴 |
| DUCK | 6 | 上下双横线 + 端部竖线（鸭脚底板） | 2 |
| GUID | 34 | 竖线 + 密集扇形排线 + 底梁（导向架） | 2 |
| HANG | 13 | 闭合三角 + 密排扇 + 顶梁（吊架） | 2 |
| SKID | 4 | 闭合三角 + 底座横线（撬架） | 2 |
| SLVE | 6 | 双横线 + 两侧竖线（滑座） | 0 顺管道 |
| SPRG | 9 | 三角 + 吊杆 + 锯齿弹簧圈（弹簧支吊架） | 2 |

SKEY 官方语义（SystemMaterialData.xml）：
`01HG`=默认承重支撑、`ANCH`=固定架、`DUCK`=鸭脚架、`GUID`=导向架、
`SKID`=撬架、`SPRG`=弹簧支吊架、`HANG`=吊架、`SLVE`=滑动架。

## 五、新增符号的步骤

1. 在 Smart Isogen 的 Symbol Editor 中编辑/选择符号
2. 导出为 `.asc` 文件
3. 放入本目录（`symbols\`），任意文件名
4. 重新出图即自动生效（渲染器启动时加载目录下全部 `.asc`，SKEY 先到先得）

## 六、解码过程笔记（备查）

- 关键突破来自逐符号对照：01HG"只有两条平行线"排除了一类解释；
  ANCH"双箭头、直线穿过定位点"补全了首点离开段规则；
  SKID/SPRG 的闭合三角与锯齿弹簧验证了记录链式连续
- 曾踩过的坑：501 头部 origin ≠ 连接点；元素号不代表方向变体；
  一个文件多个符号可共用末尾一个 999（需遇 501 即落盘上一符号）
